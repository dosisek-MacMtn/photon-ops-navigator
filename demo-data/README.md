# Deterministic demo data

The seed is generated by `backend/app/demo_data.py`; it is code-defined so every reset produces the same topology and incident outcomes.

The fictional Dexter, Maine network contains:

- 1 POP, 2 cabinets, 8 splice closures, 30 poles, and 50 service locations
- 6 backbone, 20 distribution, and 50 service-drop cables
- 15 active circuits with ordered path segments
- Known high-loss splice, reflective-event, and backbone-cut incidents

No record represents a real subscriber, address, VETRO schema, or VETRO API response.
